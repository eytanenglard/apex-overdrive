# 🏎️ APEX OVERDRIVE: משחק מרוצים וחשבון (גרסה 2, מותאם לכיתה ה׳)

משחק מרוצים תלת-ממדי בדפדפן. נוהגים, מתחמקים מקוצים, עוצרים בתחנות, פותרים שאלות בחשבון, והצוות ממלא דלק ומחליף גלגלים.

## איך מפעילים
- לוחצים פעמיים על `start-game.bat`, או פותחים את `index.html` בכרום או באדג׳.
- לשליחה לתלמידים: מעלים את התיקייה לאתר סטטי (למשל GitHub Pages) ושולחים את הקישור. אין צורך בשרת או בהתקנה.

## מה במשחק
- **נהיגה:** חצים או W A S D להחלפת נתיב ולגז, רווח לקפיצה וסלטה, Shift לטורבו, C להחלפת מצלמה (כולל «מצלמת נהג» שמראה את הפנים שלכם), T להמראת הטסלה המעופפת.
- **קוצים על הכביש:** פסי קוצים עם שלט אזהרה לפניהם. מתחמקים בהחלפת נתיב או בקפיצה. פגיעה גורמת לפנצ׳ר: הרכב איטי עד שמחליפים גלגלים במוסך.
- **תחנות דלק ומוסכים:** הרכב נכנס לבד לתחנה ונעצר. פותרים שאלה והצוות עובד לעיני כולם: מתדלקים (צינור, משאבה עם מונה), מחליפים גלגלים (ג׳קים, אקדחי ברגים), מתקינים טורבו, בולמים או מגן.
- **שאלות חשבון:** סיפורים קצרים מהתחנה (כפל, חילוק, חיסור, שברים, היקף ושטח), עם הסבר בסרטון צעד אחר צעד. תשובה נכונה **+10** נקודות, שלוש ברצף **+25** בונוס, טעות **−10** נקודות.
- **קניות:** מתחילים עם 250 נקודות. מקום ראשון 200, שני 150, שלישי 100, כל משתתף 50. בחנות קונים רכבים, אביזרים ומסלולים, עם חלון אישור.
- **הנהג שלי:** מעלים תמונה או מצלמים סלפי (התמונה נשארת רק במחשב, לא נשלחת לשום מקום). היא מופיעה על הנהג בתוך הרכב, בפינת המסך ובלוח התוצאות.
- **גרפיקה:** מתג «גרפיקה גבוהה / קלה» במסך הראשי. מחשבים חלשים עוברים אוטומטית לגרפיקה קלה. אפשר לכפות עם `?q=low` או `?q=high` בסוף הכתובת.

## מבנה הקוד
| קובץ | תפקיד |
|---|---|
| `js/game.js` | לולאת המשחק, פיזיקה, מצלמות, HUD |
| `js/game-pit.js` | כניסה לתחנה, פאנל השאלות, קוצים ופנצ׳ר, קנייה, תמונת נהג, איכות גרפיקה |
| `js/data.js` | רכבים, מסלולים, כלכלה (`ECONOMY`), שמירה ב-localStorage |
| `js/math-engine.js`, `js/math-stories.js` | שאלות חשבון וסרטון ההסבר |
| `js/avatar.js` | תמונת הנהג (העלאה, סלפי, שמירה מקומית) |
| `js/vehicles3d.js` | חמשת הרכבים והנהג |
| `js/pit3d.js` | תחנות הדלק, המוסכים והצוות |
| `js/env3d.js` | הסביבה סביב הכביש (שמיים, שטח, כביש, עצים) |
| `js/world3d.js`, `js/physics-track.js` | בניית הכביש והמכשולים, קוצים, חישוקים |

`dev/` מכיל דפי בדיקה והערות פיתוח, ואינו נחוץ להפעלת המשחק.
